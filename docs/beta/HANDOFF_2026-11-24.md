## 2. Reviewed, no defect found (by reading, plus existing tests)

- **Decoder safety:** every read is bounds-checked (`get`), varint stops at 10 bytes, strings max 255 bytes, entities only created per op so memory is bounded by frame size. Server never decodes binary input (ignores Binary frames); JSON input as before.
- **Leave and re-enter inside one keyframe interval:** a slot that vanishes is sent as `leave` to every served client that knew it, and only reused the snapshot after (`pending_free`). Clients not served in a snapshot are dropped and restart with a keyframe.
- **Zone travel / BG entry/exit to another zone:** new act resets the client view, so a keyframe follows. **Same-zone teleport** (BG arena when queued from Nephilim, respawn at an inn in the same zone, `tp`): no keyframe, the enter/leave scan runs every 4 snapshots, so the new surroundings can arrive up to ~0.4 s late. Acceptable, not fixed.
- **Reconnect:** new connection id = fresh view = keyframe.
- **Resync:** rate-limited to once per 2 s; the request is remembered, so a refused one is served later.
- **wasm transport:** same `Inbound` decoder, `BinaryType::Arraybuffer` set, web-sys feature present. Never compiled (wasm target off limits).
- **XP migration:** proportional to the old fraction, clamped at 60, idempotent (existing test). Quest store: old text ids load, packed on save (existing db test).
- **Memory:** server slot table grows to the peak watched entity count and is never shrunk (bounded); client views are dropped when unserved. Server RSS 91-109 MB at 1001 connections.

## 6. Skeptical verdict: would millions want to play this?

Not today. The engineering (1000 on one screen at 22 KB/s) is a real strength, but what the player sees and does is not yet competitive with free MMOs that already have millions. Top 10 gaps:

1. Art: crowds are block figures, characters are simple; no art direction strong enough to sell in a screenshot.
2. Combat feel: no animation weight, hit reactions or sound design proven in play.
3. Content depth: generated board quests dominate; the hand-written story is thin past the first hour.
4. Endgame: one battleground with no matchmaking by rating, no raids proven with real players.
5. Real-network play never tested: latency, packet loss, real shard under load.
6. Web build (the main reach channel) not compiled for this branch.
7. Social systems (guilds, chat, groups) exist but have never had more than one human in them.
8. Onboarding/UI polish: scrolling, clipped labels, HUD overlap remain open.
9. No accounts/anti-cheat/abuse tooling at scale (honor farming shows how exploits appear).
10. No audience: no community, marketing, store pages, or retention data; a niche biblical antediluvian theme narrows appeal.
