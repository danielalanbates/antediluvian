## 5. Top 10 gaps

1. **"1000 players on screen" is not reachable.** The server sends at most 150 entities per client; the client now draws at most 40 other players as rigs. The crowd you can see is 150.
2. **Bandwidth.** About 250 KB/s per client in a full crowd, as uncompressed JSON. 1000 clients is about 250 MB/s. B11 is the gate for any hosted crowd.
3. **No human has played this branch.** Every window, button, right-click, tooltip, hotkey and the whole builder were driven by script only. Expect input bugs in the first real session.
4. **Frame rate is 42-52 with nobody around.** The cost is the scene (grass, props, shadows), not the crowd. No profile taken.
5. **Windows clip instead of scrolling**, cannot be dragged, and have no text fields. A long bag, board or who list is cut off.
6. **Art is inconsistent.** Chibi KayKit heroes, Quaternius humanoids, procedural beasts and block figures side by side; 56 of 64 abilities have no icon; classes 5-8 reuse four rigs; bag labels are clipped ("Hearthst").
7. **Combat feel is unknown.** No aura list on the wire (enemy debuffs invisible), cooldown sweep is low-contrast, no sound check, other players show no name plate in the crowd shots.
8. **Server serializes every entity of a zone at 10 Hz** whether or not anyone is near, and does not use the AoI grid for snapshots.
9. **Login.** Real Sign in with Apple needs owner steps; the server does not verify Apple's token; no name blocklist.
10. **Known open:** XP curve overflows near level 55; live shard is on an older protocol (a version 16 client cannot log in to it); web bundle grows about 13 MB from the new humanoid and beast models; wasm build of this branch never attempted.

Would a first-hour tester enjoy it? Partly. Creation, the first quest, the map
and the windows now read like an MMO, and that is new. The hour would still be
spent finding input bugs and reading small monospace text. Would millions play
it? No. It is a systems-complete prototype with borrowed art.

## 6. Pathways for the next AI

### First: one real session
Owner (or an agent he allows to use the window) plays 20 minutes: builder by
mouse, every hotkey, buy / sell / repair / fly / turn in / release. Log each
failure. Nothing else on this list is worth more.

### B10 battlegrounds
- Sim: a `Zone` per instance keyed by id, not only by `Act`; 10v10 queue in a module beside `server/src/track.rs`; relic entity with carry / drop / capture.
- Protocol: `BgQueue`, `BgLeave`, `ServerMsg::BgState { score, relic, timer }`; flood-gate the client messages; add arms to `local.rs` (exhaustive match).
- Client: score strip in a new `win/` module; reuse the zone banner for start / end.
- Honor reward through the existing honor tick.

### B11 delta + binary snapshots
- Order: (a) per-client entity baseline, send only changed fields; (b) bincode or postcard frames behind a `Login` capability flag so old clients keep JSON; (c) quantise x, y, rot to u16; (d) send `look`, `appearance`, name and gear once when an entity enters view, not every frame.
- Build snapshots from `World::visible_entities` (the grid) and serialize only entities someone can see.
- Raise the 150 cap only after measuring; raise `MAX_PLAYER_RIGS` (client `main.rs`) only with a frame-time measurement.
- Target to prove: 1000 bots, tick under 50 ms, under 30 KB/s per client.

### B12 shard redeploy
- Owner go-ahead every time (`docs/beta/WEB_PLAY.md` step 3). Protocol 16 breaks older clients: redeploy the shard and the web client together.
- Old saves load (tested). Back up the VM database first.
- Dev shard first (`scripts/deploy_dev.sh`), then production.

### Web gate + deploy
1. `scripts/build_web.sh` (not run on this branch; expect cfg fixes; wasm must stay under 25 MB).
2. Gate from `docs/verification/web-play-staging-checklist.md` against a fresh server on 8797.
3. Private dev site (`docs/beta/DEV_SITE.md`), then `/antediluvia` only after it passes there.
4. Archive the previous bundle.

### .app build
- `scripts/make_app.sh` builds, signs and installs. Only when the owner asks, and never while his game is running. Archive the previous version in `dist/`.
- The 16 MB stack workaround (`RUST_MIN_STACK` in `main()`) must survive in the bundled client.

### Cheap fixes waiting
- Scrolling for windows; name plates for nearby players; brighter cooldown overlay; wider bag labels.
- Skip `assets/models/quaternius` and `kaykit` in `perf::preload_assets` (local raw kits log "Path not found" for their textures at every start).
- Throttle the minimap region label to twice a second.
